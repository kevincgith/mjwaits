# Tile art

These tile faces are adapted from the oblique mahjong tile set on Wikimedia
Commons (files `MJw1-.svg` ... `MJj1-.svg`), drawn by **Cangjie6**; the
circle tiles build on an original by **Jerry Crimson Mann** with work by
**User:Dewcl**.

- Source: https://commons.wikimedia.org/wiki/Category:SVG_Oblique_illustrations_of_Mahjong_tiles
- License: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

Changes made here: each tile was cropped to its face - the 3D body (green
back, bevels, shadow and highlights) removed and the tinted face replaced
with plain white - editor metadata stripped, and files renamed to the app's
tile codes (`m1`-`m9` 萬, `t1`-`t9` 筒, `b1`-`b9` 索, `z1`-`z7`
東南西北中發白, `flower1`-`4` 梅蘭菊竹, `season1`-`4` 春夏秋冬, `joker`).

These adapted files are likewise licensed under CC BY-SA 4.0.
